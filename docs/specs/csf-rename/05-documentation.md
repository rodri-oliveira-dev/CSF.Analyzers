# CSF rename - documentation

## Resultado

Esta etapa migrou documentacao publica, documentacao operacional, specs de proximos analyzers e instrucoes de agentes para `CSF`.

## Escopo validado

- README, CHANGELOG e docs publicas usam `CSF.Analyzers`.
- Docs de pacote e de regras usam PackageIds `CSF.Analyzers.*`.
- Guias operacionais usam `CSF.Analyzers.slnx`.
- Instrucoes de agentes apontam para paths `CSF.Analyzers.*`.
- URLs ativas apontam para `https://github.com/rodri-oliveira-dev/CSF.Analyzers`.
