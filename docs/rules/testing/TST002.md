# TST002: Warn on exclusions in BeEquivalentTo()

| Campo | Valor |
| ----- | ----- |
| Pacote | `CSF.Analyzers.Testing` |
| Categoria | TestQuality |
| Severidade | Info |
| Estado padrão | Opt-in |

## Objetivo

Alertar quando testes usam métodos `Excluding*` dentro das opções de `BeEquivalentTo()` do FluentAssertions.

## Motivação

Exclusões em equivalência podem tornar testes permissivos demais e esconder regressões em partes do objeto comparado.

## Código não conforme

```csharp
actual.Should().BeEquivalentTo(
    expected,
    options => options.Excluding(member => true));

actual.Should().BeEquivalentTo(
    expected,
    options => options.ExcludingMissingMembers());
```

## Código conforme

```csharp
actual.Should().BeEquivalentTo(expected);
```

## Heurística

A regra só roda em contexto de teste reconhecido. Ela confirma que `BeEquivalentTo` pertence ao namespace `FluentAssertions` e varre apenas o corpo do delegate de opções, reportando invocações `Excluding*` em `FluentAssertions.Equivalency`.

## Opções públicas

Não há opções públicas específicas.

## Fallback de configuração

Sem configuração, a regra fica desabilitada. Ative com:

```ini
[*.cs]
dotnet_diagnostic.TST002.severity = info
```

## Limitações

A regra não interpreta se a exclusão é justificada. Ela também não avalia chamadas fora do delegate de opções de `BeEquivalentTo()`.

## Impacto esperado

Incentiva comparações mais completas e torna exceções de equivalência mais visíveis em revisão.

## Suppression

Suprima localmente quando a exclusão é necessária, por exemplo para campos gerados ou propriedades fora do objetivo do teste.

## Relação com ferramentas externas

Nenhum substituto externo direto foi confirmado para esta política.
