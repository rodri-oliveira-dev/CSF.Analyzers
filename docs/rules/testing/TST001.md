# TST001: Restrict usage of NSubstitute Arg.Any()

| Campo | Valor |
| ----- | ----- |
| Pacote | `Swa.Analyzers.Testing` |
| Categoria | TestQuality |
| Severidade | Info |
| Estado padrão | Opt-in |

## Objetivo

Restringir `NSubstitute.Arg.Any<T>()` em testes, permitindo apenas a convenção de asserção negativa com `DidNotReceive()` ou `DidNotReceiveWithAnyArgs()`.

## Motivação

`Arg.Any<T>()` é um matcher amplo. Em asserts positivos ou setups, ele pode esconder valores importantes e reduzir precisão do teste.

## Código não conforme

```csharp
sender.Received().Send(Arg.Any<string>());
sender.Send(Arg.Any<string>());
```

## Código conforme

```csharp
sender.DidNotReceive().Send(Arg.Any<string>());
sender.DidNotReceiveWithAnyArgs().Send(Arg.Any<string>());
```

## Heurística

A regra só roda quando encontra atributos de teste conhecidos e referência a `NSubstitute.Arg`. Ela reporta `Arg.Any()` fora de contexto de teste ou quando o matcher não é argumento direto de uma chamada precedida por `DidNotReceive()`/`DidNotReceiveWithAnyArgs()` do namespace `NSubstitute`.

## Opções públicas

Não há opções públicas específicas.

## Fallback de configuração

Sem configuração, a regra fica desabilitada. Ative com:

```ini
[*.cs]
dotnet_diagnostic.TST001.severity = info
```

## Limitações

A regra depende de reconhecimento semântico de NSubstitute e de contexto de teste. Ela não oferece allowlist de métodos.

## Impacto esperado

Aumenta precisão de testes que usam mocks e torna expectativas positivas mais explícitas.

## Suppression

Suprima quando a equipe aceitar matcher amplo naquele teste específico e a intenção estiver clara.

## Relação com ferramentas externas

Nenhum substituto externo direto foi confirmado para esta convenção específica.
