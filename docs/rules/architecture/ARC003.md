# ARC003: Prohibit verbs in HTTP routes

| Campo | Valor |
| ----- | ----- |
| Pacote | `Swa.Analyzers.Architecture` |
| Categoria | Design |
| Severidade | Info |
| Estado padrão | Opt-in |

## Objetivo

Detectar verbos de comando em segmentos literais de rotas HTTP declaradas com atributos MVC/Web API e Minimal APIs.

## Motivação

APIs orientadas a recursos tendem a usar substantivos no caminho e expressar ação pelo método HTTP. Esta é uma política de design, não uma regra universal de ASP.NET.

## Código não conforme

```csharp
[HttpPost("customers/create")]
public IActionResult CreateCustomer() => Ok();

app.MapPost("/apolices/emitir", () => Results.Ok());
```

## Código conforme

```csharp
[HttpPost("customers")]
public IActionResult CreateCustomer() => Ok();

app.MapPost("/apolices", () => Results.Ok());
```

## Heurística

A regra analisa apenas strings constantes de rota. Segmentos com `{}`, `[]` ou formato de versão como `v1` são ignorados. Segmentos são quebrados por `-`, `_`, `.`, e transições camel case. Idiomas aceitos: `en-US` e `pt-BR`.

## Opções públicas

```ini
[*.cs]
dotnet_diagnostic.ARC003.severity = info
dotnet_diagnostic.ARC003.route_language = pt-BR
dotnet_diagnostic.ARC003.additional_verbs = ["ativar", "inativar", "recalcular"]
```

- `route_language`: `en-US` ou `pt-BR`.
- `additional_verbs`: array JSON de verbos adicionais.

## Fallback de configuração

Sem `route_language`, usa `en-US`. Valor inválido também volta para `en-US`. `additional_verbs` ausente ou JSON inválido é ignorado; valores vazios são descartados.

## Limitações

A regra não inspeciona nomes de controllers, actions, métodos C# ou método HTTP. Rotas não constantes não são avaliadas.

## Impacto esperado

Ajuda times que adotam APIs orientadas a recursos a manter consistência de rotas.

## Suppression

Prefira configurar `additional_verbs` apenas para verbos que o time quer proibir. Suprima quando uma rota por contrato externo precisa manter verbo.

## Relação com ferramentas externas

Regras externas de roteamento podem validar formato, mas nenhum substituto direto foi confirmado para verbos em segmentos com idioma configurável.
