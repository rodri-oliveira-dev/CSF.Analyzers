# ARC005: Evitar propriedades MSBuild duplicadas

| Campo | Valor |
| ----- | ----- |
| Pacote | `CSF.Analyzers.Architecture` |
| Categoria | Maintainability |
| Severidade | Info |
| Estado padrão | Opt-in |

## Objetivo

Detectar propriedades MSBuild repetidas em `.csproj` quando a mesma propriedade existe no `Directory.Build.props` ancestral mais próximo recebido como `AdditionalFiles`.

## Motivação

Propriedades duplicadas entre arquivos de projeto e `Directory.Build.props` podem divergir e dificultar manutenção.

## Código não conforme

```xml
<!-- Directory.Build.props -->
<Project>
  <PropertyGroup>
    <Nullable>enable</Nullable>
  </PropertyGroup>
</Project>
```

```xml
<!-- MyApp.csproj -->
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <Nullable>enable</Nullable>
  </PropertyGroup>
</Project>
```

## Código conforme

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
  </PropertyGroup>
</Project>
```

## Heurística

A regra roda no fim da compilação sobre `AdditionalFiles`. Ela lê `.csproj` e `Directory.Build.props`, ignora `PropertyGroup` e propriedades com `Condition`, usa o `Directory.Build.props` ancestral mais próximo e reporta propriedades duplicadas não ignoradas.

## Opções públicas

```ini
[*.csproj]
dotnet_diagnostic.ARC005.severity = info
dotnet_diagnostic.ARC005.ignored_properties = ["TargetFramework", "TargetFrameworks", "AssemblyName", "RootNamespace"]
dotnet_diagnostic.ARC005.compare_values = true
```

No consumo via NuGet, o pacote inclui um target `buildTransitive` que envia o `.csproj` e o `Directory.Build.props` do projeto como `AdditionalFiles`. Em builds que não aplicam severidade de `.editorconfig` a diagnósticos reportados em `AdditionalFiles`, ative a regra em `.globalconfig`:

```ini
is_global = true
dotnet_diagnostic.ARC005.severity = info
```

- `ignored_properties`: array JSON de propriedades ignoradas.
- `compare_values`: booleano que exige mesmo valor para reportar quando `true`.

## Fallback de configuração

Sem configuração, ignora `TargetFramework`, `TargetFrameworks`, `AssemblyName`, `RootNamespace`, `PackageId`, `Version`, `Authors` e `Description`. JSON inválido volta para essa lista padrão. `compare_values` ausente ou inválido volta para `true`.

## Limitações

A regra só funciona quando arquivos MSBuild são fornecidos como `AdditionalFiles`. Ela não interpreta condições, imports complexos ou propriedades calculadas.

## Impacto esperado

Ajuda a manter configuração MSBuild centralizada e reduz drift entre projetos.

## Suppression

Prefira adicionar a propriedade a `ignored_properties` quando a duplicação é política do repositório. Use suppression para casos pontuais.

## Relação com ferramentas externas

Nenhum substituto externo direto foi confirmado para esta análise via `AdditionalFiles`.
