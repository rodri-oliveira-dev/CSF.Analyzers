# ARC004: Proibir setters públicos em entidades de domínio

| Campo | Valor |
| ----- | ----- |
| Pacote | `Swa.Analyzers.Architecture` |
| Categoria | Design |
| Severidade | Info |
| Estado padrão | Opt-in |

## Objetivo

Detectar propriedades com setter público, ou setter interno quando não autorizado, em entidades de domínio.

## Motivação

Entidades de domínio normalmente protegem invariantes por métodos de comportamento e setters privados. Esta é uma política DDD, não uma exigência geral de C#.

## Código não conforme

```csharp
namespace MyApp.Domain.Entities;

public sealed class Customer
{
    public string Name { get; set; } = "";
}
```

## Código conforme

```csharp
public sealed class Customer
{
    public string Name { get; private set; } = "";

    public void Rename(string name)
    {
        Name = name;
    }
}
```

## Heurística

A regra analisa propriedades de classes não record e não estáticas. Ela identifica entidades por marcadores de namespace como `Domain.Entities`/`Domain.Aggregates`, por tipos base padrão (`Entity`, `AggregateRoot`, `IEntity`, `IAggregateRoot`) ou por configuração. Tipos de teste são ignorados. `init` não é reportado.

## Opções públicas

```ini
[*.cs]
dotnet_diagnostic.ARC004.severity = info
dotnet_diagnostic.ARC004.entity_namespaces = ["MyApp.Domain.Entities", "MyApp.Domain.Aggregates"]
dotnet_diagnostic.ARC004.entity_base_types = ["Entity", "AggregateRoot"]
dotnet_diagnostic.ARC004.allow_internal_setters = false
```

## Fallback de configuração

Arrays ausentes, vazios ou inválidos usam lista vazia configurada, além dos marcadores e tipos padrão internos. `allow_internal_setters` ausente ou inválido volta para `false`.

## Limitações

A regra não valida invariantes reais. Ela usa sinais estruturais de entidade e pode precisar de calibração em modelos anêmicos legados ou DTOs em namespaces de domínio.

## Impacto esperado

Reduz mutabilidade acidental em modelos de domínio que adotam encapsulamento.

## Suppression

Suprima quando a mutabilidade pública faz parte de contrato externo, serialização ou compatibilidade legada. Para padrões recorrentes, ajuste namespaces ou tipos base.

## Relação com ferramentas externas

Regras gerais de imutabilidade são relacionadas, mas não substituem a detecção contextual de entidades de domínio.
